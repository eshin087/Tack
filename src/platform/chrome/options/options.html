Pin a site: filter (or any modifier) to every search. Define one or more profiles below — the one flagged as Default is applied automatically to your Google, Bing, DuckDuckGo, Yahoo, Ecosia, and Brave searches.

Keyboard shortcuts (Chrome-managed)

These work everywhere in Chrome. Chrome requires Ctrl, Alt, or Cmd as a modifier — bare Shift+letter combos aren't allowed here.

In-page keybindings

Any key combo (including bare Shift+Q). Only active on search results pages, and ignored while you're typing in the search box.

Examples: site:reddit.com, site:github.com, filetype:pdf, inurl:tutorial, -site:pinterest.com

Profiles sync across your Chrome installs via chrome.storage.sync.
